# Threat-Classification-Dashboard
Developed a Threat Classification Dashboard using Python and a Kaggle dataset. Performed data cleaning, preprocessing, EDA, and machine learning model evaluation using a confusion matrix. Created an interactive Streamlit dashboard with line charts, bar charts, and pie charts to visualize network traffic and classify BENIGN and ATTACK activities.
